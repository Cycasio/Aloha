# Aloha Ukulele Tabs

一個純前端的 Ukulele 打譜小工具，提供四弦指板譜編輯、和弦備註以及文字匯出。直接開啟 `index.html` 即可使用，無需伺服器或額外套件。

## 功能
- 編輯拍號（2/4、3/4、4/4、6/8）與切分（四分、八分、十六分），小節會自動補齊格線。
- 每個小節包含和弦列與 G C E A 四弦格子，點擊即可輸入品位數字。
- 小節複製／刪除與整份譜清空功能，快速嘗試不同編排。
- 匯出為易讀的純文字譜，可直接貼到訊息或筆記。

## 使用方式
1. 開啟 `index.html`。
2. 右上角設定標題、速度、拍號與切分。
3. 在格子輸入品位，空白會自動轉成「0」代表空弦；輸入 `-` 代表留白。
4. 按「匯出文字譜」即可在側欄取得結果並複製。

## 開發
僅包含 HTML / CSS / 原生 JavaScript 檔案，無需安裝依賴。
